UX 系統數據集 for AI Agent (UX System Dataset for AI Agent)

Loading stats...

本專案是一個面向 UX 設計師 的教育資源，旨在從人類用戶的瀏覽角度， 幫助理解 AI Agent 的思維鏈 (Chain-of-Thought) 如何運用設計系統進行決策。 涵蓋風格、色彩、字體、技術棧、UX 準則（含 Dark Pattern 辨識），以及調用 AI 技能 (UX agent skills)。

This project serves as an educational resource for UX designers to understand, from a human user's browsing perspective, how AI Agent Chain-of-Thought (COT) leverages design systems for decision-making. It covers styles, colors, typography, tech stacks, UX guidelines (including dark pattern detection), and calling AI skills (UX agent skills).

🎨 色彩理論 (Color Theory)

色彩在使用者看到內容之前就開始傳達訊息。精心設計的配色方案可以幫助使用者導航、理解優先順序，並與您的品牌建立連結。

🔺 三元 Triadic

色輪等距 120°，平衡且活潑

🌈 類似 Analogous

色輪相鄰，和諧且自然

🧠 心理學原理速查 (Psychology Principles Quick Reference)

Peak-End Rule

人們根據體驗的峰值和結尾來評判整體體驗，而非平均值。

應用：確保關鍵流程（如註冊、購買）的結尾正面。
Jakob's Law

使用者傾向期望你的網站與他們已知的網站運作方式相同。

應用：遵循常見 UI 模式，減少學習成本。
Cognitive Dissonance

當行為與信念矛盾時，人們會感到不適並尋求一致性。

應用：避免讓使用者做出與其價值觀矛盾的選擇。
Loss Aversion

失去某物的痛苦是獲得同等價值事物快樂的兩倍。

⚠️ 易被濫用於 Dark Patterns。

🏷️ Dark Pattern 分類法 (Deceptive Pattern Taxonomy)

Data Hostage 資料挾持

讓使用者擔心刪除帳號會失去重要資料。

Confirmshaming 羞辱確認

使用羞辱性語言讓使用者不敢選擇退出選項。

Interaction Friction 互動摩擦

在不希望使用者執行的操作上增加額外步驟。

Roach Motel 易進難出

訂閱容易取消難，註冊容易刪帳難。

Hidden Costs 隱藏成本

在結帳最後才顯示額外費用。

Trick Questions 陷阱問題

使用雙重否定或混淆語言誤導使用者。
